# Graph Functional Tests

Tests for the **Graph** layer, focused on validating use cases through GraphQL queries and mutations.

## Responsibilities
- Execute GraphQL queries and mutations
- Validate operation results
- Verify resolver behavior
- Ensure correct mapping to Application use cases

## Dependencies
- Depends on **Graph**
- Uses external testing libraries

## Notes
These tests validate use cases through the GraphQL API, involving multiple components working together.
